# mernstack
 
Purpose: Website  to generate and download AI-generated images

Tech Stack:
HTML5
CSS3
JavaScript (ES6+)
React.js

 Features:
Generate images based on user input
Download generated images
Responsive and user-friendly UI
Easily extendable to connect with image generation APIs (e.g., DALL·E, Stability AI)

 Project Structure (Simplified)
/public – Static files (e.g., index.html)
/src – React components and logic
/components – Reusable components
mern.js – Main app component
index.js – Entry point
/styles – CSS files
package.json – Dependencies and scripts
README.md – Project documentation
